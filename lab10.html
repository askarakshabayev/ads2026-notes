Introduction to Graphs

6 min board

What to say

  • A graph is a set of vertices and a set of edges between pairs of them: G = (V, E).
  • Graphs model relationships — friendships, roads, network links, hyperlinks, dependencies between tasks.

G = (V, E)

  • a set of vertices (or nodes)
  • a set of edges connecting pairs of vertices

Notation: G = (V, E), where V is the set of vertices and E the set of edges.

Example:

Vertices: {A, B, C, D}
Edges: {(A,B), (B,C), (C,D), (A,D)}

Visual representation:
    A --- B
    |     |
    D --- C

Why use graphs?

  • Social networks: people are vertices, friendships are edges
  • Maps and navigation: cities are vertices, roads are edges
  • Computer networks: computers are vertices, connections are edges
  • Web pages: pages are vertices, hyperlinks are edges
  • Dependencies: tasks are vertices, dependencies are edges
02

Types of Graphs

14 min board

What to say

  • Eleven words, in pairs where possible: directed or undirected, weighted or unweighted, cyclic or acyclic, connected or disconnected — then complete, tree and bipartite.
  • A DAG — directed and acyclic — is the graph of the topological sort in the next lecture.
  • A tree is a connected acyclic graph: n vertices, exactly n − 1 edges, exactly one path between any two vertices.
  • Bipartite: the vertices split into two sets and every edge goes between the sets. A triangle is the smallest graph that is not bipartite.

1 · Directed graph (digraph)

Edges have a direction — from one vertex to another.

    A --> B
    ↑     ↓
    D <-- C

Edges: (A,B), (B,C), (C,D), (D,A)

Applications: web page links (one-way), task dependencies, state transitions.

2 · Undirected graph

Edges have no direction — the connection goes both ways.

    A --- B
    |     |
    D --- C

Edges: (A,B), (B,C), (C,D), (A,D)

Applications: social networks (friendship is mutual), road networks (two-way roads).

3 · Weighted graph

Edges have weights — costs, distances, capacities.

    A --5-- B
    |       |
    3       7
    |       |
    D --2-- C

Edges: (A,B,5), (A,D,3), (B,C,7), (C,D,2)

Applications: road networks (distances), network routing (latency), flight routes (costs).

4 · Unweighted graph

All edges have equal weight (or weight = 1).

    A --- B
    |     |
    D --- C

5 · Cyclic graph

Contains at least one cycle — a path from a vertex back to itself.

    A --- B
    |     |
    D --- C

Cycle: A → B → C → D → A

6 · Acyclic graph

Contains no cycles.

    A --- B --- C
          |
          D

DAG (Directed Acyclic Graph) — a directed graph with no cycles:

  • used in task scheduling
  • dependency resolution
  • topological sorting

7 · Connected graph

There is a path between every pair of vertices.

    A --- B
    |     |
    D --- C

8 · Disconnected graph

Some vertices are not reachable from others.

    A --- B     E --- F
    |     |
    D --- C

9 · Complete graph

Every pair of vertices is directly connected.

    A --- B
    |\   /|
    | \ / |
    |  X  |
    | / \ |
    |/   \|
    D --- C

Edges: (A,B), (A,C), (A,D), (B,C), (B,D), (C,D)

10 · Tree

A connected acyclic graph.

        A
       / \
      B   C
     / \
    D   E

Properties:

  • N vertices have exactly N − 1 edges
  • exactly one path between any two vertices
  • removing any edge disconnects the graph

11 · Bipartite graph

Vertices can be divided into two sets such that edges only connect vertices from different sets. No edges exist within the same set.

Set 1          Set 2

  0 ----------- 1
   \           /
    \         /
     \       /
      \     /
       \   /
        \ /
         X
        / \
       /   \
      /     \
     /       \
    /         \
   /           \
  2 ----------- 3

Set 1: {0, 2}
Set 2: {1, 3}

Edges: (0,1), (0,3), (2,1), (2,3)

Verification:
- 0 connects to 1: Set 1 → Set 2 ✓
- 0 connects to 3: Set 1 → Set 2 ✓
- 2 connects to 1: Set 1 → Set 2 ✓
- 2 connects to 3: Set 1 → Set 2 ✓
- No edges within Set 1 (0 and 2 NOT connected) ✓
- No edges within Set 2 (1 and 3 NOT connected) ✓

This IS a bipartite graph!

Not bipartite — the triangle

    0
   / \
  1---2

This is NOT bipartite because:
- If we put 0 in Set 1, then 1 and 2 must be in Set 2
- But 1 and 2 are connected to each other
- This violates the bipartite rule!

Applications of bipartite graphs: matching problems (students to projects), job assignments (workers to tasks), task scheduling.

Graph Terminology

4 min board

The words we will use

  • Vertex (node): a point in the graph
  • Edge: a connection between two vertices
  • Adjacent vertices: two vertices connected by an edge
  • Degree: the number of edges at a vertex — in-degree (incoming) and out-degree (outgoing) in a directed graph
  • Path: a sequence of vertices connected by edges
  • Cycle: a path that starts and ends at the same vertex
  • Connected: a path exists between every pair of vertices
  • Component: a maximal connected subgraph
04

Graph Representations

28 min code

What to say

  • Three ways to store the same graph. Use the 4-cycle 0 — 1 — 2 — 3 — 0 for all three and keep it on the board.
  • Adjacency matrix: matrix[i][j] says whether there is an edge. O(1) to check an edge, but O(V²) memory.
  • Adjacency list: adj[i] holds the neighbours of i. O(V + E) memory — the default for traversals.
  • Edge list: just the pairs. Simple, and exactly what Kruskal needs later; bad for traversal.
  • Undirected means both directions: every edge is written into the matrix or the list twice.

1 · Adjacency matrix

A 2D array where matrix[i][j] tells whether there is an edge from vertex i to vertex j.

  • Unweighted: matrix[i][j] = 1 if the edge exists, 0 if not
  • Weighted: matrix[i][j] = weight if the edge exists, ∞ or 0 if not

Example. Graph:

    0 --- 1
    |     |
    3 --- 2

Adjacency matrix (undirected):

     0  1  2  3
  0 [0, 1, 0, 1]
  1 [1, 0, 1, 0]
  2 [0, 1, 0, 1]
  3 [1, 0, 1, 0]

    adj[v][u] = weight;

05

Breadth-First Search (BFS)

12 min board demo: grid

What to say

  • BFS explores the graph level by level from a source: first all neighbours, then all neighbours of neighbours, and so on.
  • The order is kept by a queue — first in, first out.
  • Mark a vertex visited when it is put into the queue, not when it is taken out — otherwise it can enter the queue several times.
  • Run the demo in BFS mode: the visited area grows in rings, and the numbers are the distances.

BFS algorithm

  1. Start from the source vertex
  2. Visit all its neighbours (level 1)
  3. Visit all neighbours of neighbours (level 2)
  4. Continue until all reachable vertices are visited

Uses a queue (FIFO — First In, First Out).

BFS visualization

Graph:

        0
       / \
      1   2
     / \   \
    3   4   5

BFS starting from vertex 0:

Level 0: [0]
Level 1: [1, 2]
Level 2: [3, 4, 5]

Visit order: 0 → 1 → 2 → 3 → 4 → 5

BFS algorithm steps

1. Create a queue Q
2. Mark source vertex as visited
3. Enqueue source vertex
4. While Q is not empty:
   a. Dequeue vertex v from Q
   b. Process vertex v
   c. For each neighbor u of v:
      - If u is not visited:
        * Mark u as visited
        * Enqueue u

BFS Implementation

14 min code

What to say

  • Three functions over the same globals: plain BFS that prints the order, BFS that records the distance of each vertex, and BFS that records the parent of each vertex to restore a path.
  • Distance: distance[u] = distance[v] + 1 at the moment u is discovered.
  • Path: follow parent[] back from the target to the source, then reverse.

2 · BFS from a source

// BFS from source vertex
void BFS(int source) {
    queue<int> q;

    // Initialize visited array
    for (int i = 0; i < n; i++)
        visited[i] = false;

    // Start from source
    visited[source] = true;
    q.push(source);

    cout << "BFS traversal: ";

    while (!q.empty()) {
        int v = q.front();
        q.pop();

        cout << v << " ";

        // Visit all neighbors
        for (int i = 0; i < adj[v].size(); i++) {
            int u = adj[v][i];
            if (!visited[u]) {
                visited[u] = true;
                q.push(u);
            }
        }
    }

    cout << endl;
}

3 · BFS with distances

// BFS with distance tracking
void BFS_with_distance(int source) {
    queue<int> q;
    int distance[MAXN];

    // Initialize
    for (int i = 0; i < n; i++) {
        visited[i] = false;
        distance[i] = -1;
    }

    visited[source] = true;
    distance[source] = 0;
    q.push(source);

    while (!q.empty()) {
        int v = q.front();
        q.pop();

        for (int i = 0; i < adj[v].size(); i++) {
            int u = adj[v][i];
            if (!visited[u]) {
                visited[u] = true;
                distance[u] = distance[v] + 1;
                q.push(u);
            }
        }
    }

    cout << "Distances from vertex " << source << ":" << endl;
    for (int i = 0; i < n; i++) {
        cout << "Vertex " << i << ": ";
        if (distance[i] == -1)
            cout << "unreachable" << endl;
        else
            cout << distance[i] << endl;
    }
}

-1 means "not reached yet" — it doubles as the visited mark for distances.

4 · BFS with parents — the shortest path

// BFS with parent tracking (for shortest path)
void BFS_with_path(int source, int target) {
    queue<int> q;
    int parent[MAXN];

    // Initialize
    for (int i = 0; i < n; i++) {
        visited[i] = false;
        parent[i] = -1;
    }

    visited[source] = true;
    q.push(source);

    while (!q.empty()) {
        int v = q.front();
        q.pop();

        if (v == target)
            break;

        for (int i = 0; i < adj[v].size(); i++) {
            int u = adj[v][i];
            if (!visited[u]) {
                visited[u] = true;
                parent[u] = v;
                q.push(u);
            }
        }
    }

    // Reconstruct path
    if (!visited[target]) {
        cout << "No path exists" << endl;
        return;
    }

    vector<int> path;
    int current = target;
    while (current != -1) {
        path.push_back(current);
        current = parent[current];
    }

    reverse(path.begin(), path.end());

    cout << "Shortest path from " << source << " to " << target << ": ";

        q.pop();

        if (v == target)
            break;

        for (int i = 0; i < adj[v].size(); i++) {
            int u = adj[v][i];
            if (!visited[u]) {
                visited[u] = true;
                parent[u] = v;
                q.push(u);
            }
        }
    }

    if (!visited[target]) {
        cout << "No path exists" << endl;
        return;
    }

    int current = target;
    while (current != -1) {
        path.push_back(current);
        current = parent[current];

    reverse(path.begin(), path.end());

    cout << "Shortest path from " << source << " to " << target << ": ";

BFS finds the shortest path — the minimum number of edges — from the source to every other vertex.

int shortestPath(Graph& g, int source, int target) {
    vector<bool> visited(n, false);
    vector<int> distance(n, -1);
    queue<int> q;

    visited[source] = true;
    distance[source] = 0;
    q.push(source);

    while (!q.empty()) {
        int v = q.front();
        q.pop();

        if (v == target)
            return distance[target];

        for (int u : adj[v]) {
            if (!visited[u]) {
                visited[u] = true;
                distance[u] = distance[v] + 1;
                q.push(u);
            }
        }
    }

    return -1;  // No path exists
}

bool isBipartite(Graph& g) {
    vector<int> color(n, -1);
    queue<int> q;

    for (int s = 0; s < n; s++) {   // added: start from every vertex, not only 0 —
        if (color[s] != -1)          // otherwise a second component is never checked
            continue;
        color[s] = 0;
        q.push(s);

        while (!q.empty()) {
            int v = q.front();
            q.pop();

            for (int u : adj[v]) {
                if (color[u] == -1) {
                    color[u] = 1 - color[v];
                    q.push(u);
                } else if (color[u] == color[v]) {
                    return false;  // Same color as neighbor
                }
            }
        }
    }

    return true;
}

Common Questions

5 min

Q1 · When should I use an adjacency list and when a matrix?

  • Adjacency list: sparse graphs (few edges), most graph algorithms
  • Adjacency matrix: dense graphs, when you need O(1) edge lookup

Q2 · Why does BFS find the shortest path?

BFS explores vertices level by level. It visits all vertices at distance k before any vertex at distance k + 1. Therefore the first time it reaches a vertex is guaranteed to be via a shortest path.

Q3 · Can BFS work on weighted graphs?

BFS finds the shortest path in terms of the number of edges. For weighted graphs use Dijkstra's algorithm or Bellman–Ford instead.

Q4 · What is the difference between BFS and level order traversal?

They are essentially the same. Level order traversal is BFS that explicitly tracks the levels.

Q5 · How do I handle disconnected graphs in BFS?

Run BFS from each unvisited vertex to explore all components.

DFS Algorithm

10 min code

What to say

  • Recursive DFS is four lines: mark the vertex, then call DFS on every unvisited neighbour.
  • The recursion is the stack. The iterative version keeps the stack explicitly: pop a vertex, skip it if already visited, otherwise visit it and push its neighbours.
  • Push the neighbours in reverse order and the iterative version visits them in the same order as the recursive one.

Recursive implementation

#include <iostream>
#include <vector>
using namespace std;

const int MAXN = 100;
vector<int> adj[MAXN];
bool visited[MAXN];
int n;

void DFS(int v) {
    // Mark current vertex as visited
    visited[v] = true;
    cout << v << " ";

    // Visit all neighbors
    for (int i = 0; i < adj[v].size(); i++) {
        int u = adj[v][i];
        if (!visited[u]) {
            DFS(u);
        }
    }
}

int main() {
    n = 6;

    for (int i = 0; i < n; i++)

    adj[2].push_back(5);
    adj[5].push_back(2);

    for (int i = 0; i < n; i++)
        visited[i] = false;

            int u = adj[v][i];
            if (!visited[u]) {
                s.push(u);
            }
        }
    }
}

What to say

  • A connected component is a maximal set of vertices where every pair is connected by a path.
  • Loop over all vertices; every time one is still unvisited, start DFS from it and add one to the count.

Application 2: Checking if Graph is Bipartite

8 min code

What to say

  • A bipartite graph can be coloured with 2 colours so that no two adjacent vertices have the same colour.
  • DFS colours every new vertex with the opposite colour, 3 − c. A neighbour that already has colour c means "not bipartite".
  • The outer loop starts from every uncoloured vertex, so every component is checked.

Two colours by DFS

#include <iostream>
#include <vector>
using namespace std;

const int MAXN = 100;
vector<int> adj[MAXN];
int color[MAXN];  // 0 = uncolored, 1 = color1, 2 = color2
int n;

bool DFS_bipartite(int v, int c) {
    color[v] = c;

    for (int i = 0; i < adj[v].size(); i++) {
        int u = adj[v][i];

        if (color[u] == 0) {
            // Not colored yet, color with opposite color
            if (!DFS_bipartite(u, 3 - c))  // 3-1=2, 3-2=1
                return false;
        }
        else if (color[u] == c) {
            // Same color as current vertex - not bipartite
            return false;
        }
    }

    return true;
}

bool isBipartite() {
    // Initialize color array
    for (int i = 0; i < n; i++)
        color[i] = 0;

    // Check all components
    for (int i = 0; i < n; i++) {
        if (color[i] == 0) {
            if (!DFS_bipartite(i, 1))
                return false;
        }
    }

    return true;
}

int main() {
    // Example 1: Bipartite graph
    n = 4;
    adj[0].push_back(1);
    adj[1].push_back(0);

    adj[0].push_back(3);
    adj[3].push_back(0);

    adj[2].push_back(1);
    adj[1].push_back(2);

    adj[2].push_back(3);
    adj[3].push_back(2);

    cout << "Graph 1 is ";
    if (isBipartite())
        cout << "bipartite" << endl;
    else
        cout << "NOT bipartite" << endl;

    // Example 2: Not bipartite (triangle)
    for (int i = 0; i < MAXN; i++)
        adj[i].clear();

    n = 3;
    adj[0].push_back(1);
    adj[1].push_back(0);

    adj[1].push_back(2);
    adj[2].push_back(1);

    adj[2].push_back(0);
    adj[0].push_back(2);

    cout << "Graph 2 (triangle) is ";
    if (isBipartite())

    else

    return 0;
}

Application 3: Cycle Detection

12 min code

What to say

  • Undirected: during DFS, an edge to a visited vertex that is not the parent closes a cycle. The parent does not count — that is the edge we came by.
  • Directed: an edge to a visited vertex is a cycle only if that vertex is still on the current path — recStack. A vertex that is already finished is not a cycle.

Cycle detection in an undirected graph

#include <iostream>
#include <vector>
using namespace std;

const int MAXN = 100;
vector<int> adj[MAXN];
bool visited[MAXN];
int n;

bool DFS_cycle(int v, int parent) {
    visited[v] = true;

    for (int i = 0; i < adj[v].size(); i++) {
        int u = adj[v][i];

        if (!visited[u]) {
            if (DFS_cycle(u, v))
                return true;
        }
        else if (u != parent) {
            // Visited vertex that is not parent = cycle found
            return true;
        }
    }

    return false;
}

bool hasCycle() {
    // Initialize visited array
    for (int i = 0; i < n; i++)
        visited[i] = false;

    // Check all components
    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            if (DFS_cycle(i, -1))
                return true;
        }
    }

    return false;
}

int main() {
    // Example 1: Graph with cycle
    n = 4;
    adj[0].push_back(1);
    adj[1].push_back(0);

Application 4: Topological Sort

14 min code

What to say

  • A topological order of a DAG lists the vertices so that every edge (u, v) has u before v.
  • DFS gives it for free: push a vertex after all its descendants are processed. The stack, read from the top, is the order.
  • Only DAGs have one — a cycle makes it impossible. And there can be several valid orders.

Applications of topological sort

  • Task scheduling with dependencies
  • Course prerequisites
  • Build systems (compile order)
  • Package dependency resolution

Example

Task dependencies:
A → B (A must be done before B)
A → C
B → D
C → D

One valid topological order: A, B, C, D
Another valid order: A, C, B, D

DFS-based topological sort

Key idea: use DFS and add a vertex to the result when all its descendants are processed (post-order).

#include <iostream>
#include <vector>
#include <stack>
using namespace std;

const int MAXN = 100;
vector<int> adj[MAXN];
bool visited[MAXN];
stack<int> result;
int n;

void DFS_topo(int v) {
    visited[v] = true;

    // Visit all neighbors first
    for (int i = 0; i < adj[v].size(); i++) {
        int u = adj[v][i];
        if (!visited[u]) {
            DFS_topo(u);
        }
    }

    // Add current vertex to stack after visiting all descendants
    result.push(v);
}

void topologicalSort() {
    // Initialize
    for (int i = 0; i < n; i++)
        visited[i] = false;

    // Process all vertices
    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            DFS_topo(i);
        }
    }

    // Print result
    cout << "Topological order: ";
    while (!result.empty()) {
        cout << result.top() << " ";
        result.pop();
    }
    cout << endl;
}

int main() {
    n = 6;

    // DAG example
    adj[5].push_back(2);
    adj[5].push_back(0);
    adj[4].push_back(0);
    adj[4].push_back(1);
    adj[2].push_back(3);
    adj[3].push_back(1);

    cout << "Graph (directed):" << endl;
    cout << "5 -> 2, 0" << endl;
    cout << "4 -> 0, 1" << endl;
    cout << "2 -> 3" << endl;
    cout << "3 -> 1" << endl;
    cout << endl;

    topologicalSort();

    return 0;
}

2. For each unvisited vertex v:
   a. Call DFS(v)
   b. In DFS, visit all descendants first (recursively)
   c. After visiting all descendants, push v to stack
3. The stack contains topological order (top to bottom)

Important notes

  • Topological sort only works on Directed Acyclic Graphs (DAG)
  • If the graph has a cycle, topological sort is not possible
  • There can be multiple valid topological orderings
  • Time complexity: O(V + E)

Application 6: Finding Strongly Connected Components (SCC)

10 min code

What to say

  • A strongly connected component of a directed graph is a maximal set of vertices where every vertex is reachable from every other.
  • Kosaraju: two DFS passes. The first records the finish order; the second runs on the reversed graph, taking vertices from the latest finished — each run collects one SCC.

Kosaraju's algorithm

Kosaraju — the full program90 lines
#include <iostream>
#include <vector>
#include <stack>
using namespace std;

const int MAXN = 100;
vector<int> adj[MAXN];
vector<int> adj_rev[MAXN];  // Reversed graph
bool visited[MAXN];
stack<int> finishOrder;
int n;

void DFS1(int v) {
    visited[v] = true;

    for (int i = 0; i < adj[v].size(); i++) {
        int u = adj[v][i];
        if (!visited[u])
            DFS1(u);
    }

    finishOrder.push(v);
}

void DFS2(int v, vector<int>& component) {
    visited[v] = true;
    component.push_back(v);

    for (int i = 0; i < adj_rev[v].size(); i++) {
        int u = adj_rev[v][i];
        if (!visited[u])
            DFS2(u, component);
    }
}

void findSCC() {
    // Step 1: Do DFS and fill finish order
    for (int i = 0; i < n; i++)
        visited[i] = false;

    for (int i = 0; i < n; i++) {
        if (!visited[i])
            DFS1(i);
    }

    // Step 2: Do DFS on reversed graph in order of finish time
    for (int i = 0; i < n; i++)
        visited[i] = false;

    int sccCount = 0;
    while (!finishOrder.empty()) {
        int v = finishOrder.top();
        finishOrder.pop();

        if (!visited[v]) {
            vector<int> component;
            DFS2(v, component);

            sccCount++;
            cout << "SCC " << sccCount << ": ";
            for (int i = 0; i < component.size(); i++) {
                cout << component[i] << " ";
            }
            cout << endl;
        }
    }
}

int main() {
    n = 5;

    // Add directed edges
    adj[0].push_back(1);
    adj[1].push_back(2);
    adj[2].push_back(0);
    adj[1].push_back(3);
    adj[3].push_back(4);

    // Create reversed graph
    for (int v = 0; v < n; v++) {
        for (int i = 0; i < adj[v].size(); i++) {
            int u = adj[v][i];
            adj_rev[u].push_back(v);
        }
    }

    findSCC();

    return 0;
}

Application 7: Bridges and Articulation Points

10 min code

What to say

  • A bridge is an edge whose removal increases the number of connected components.
  • disc[v] is when DFS discovered v; low[v] is the earliest discovery time reachable from v's subtree using one back edge.
  • The edge v — u is a bridge when low[u] > disc[v]: nothing below u can get back above v without that edge.

Bridge (cut edge)

An edge whose removal increases the number of connected components.

Bridges — the full program72 lines
#include <iostream>
#include <vector>
using namespace std;

const int MAXN = 100;
vector<int> adj[MAXN];
bool visited[MAXN];
int disc[MAXN];  // Discovery time
int low[MAXN];   // Lowest discovery time reachable
int timer = 0;
int n;

void DFS_bridge(int v, int parent) {
    visited[v] = true;
    disc[v] = low[v] = timer++;

    for (int i = 0; i < adj[v].size(); i++) {
        int u = adj[v][i];

        if (u == parent)
            continue;

        if (visited[u]) {
            low[v] = min(low[v], disc[u]);
        } else {
            DFS_bridge(u, v);
            low[v] = min(low[v], low[u]);

            // If lowest reachable from u is higher than disc[v],
            // then v-u is a bridge
            if (low[u] > disc[v]) {
                cout << "Bridge: " << v << " - " << u << endl;
            }
        }
    }
}

void findBridges() {
    for (int i = 0; i < n; i++) {
        visited[i] = false;
        disc[i] = -1;
        low[i] = -1;
    }

    for (int i = 0; i < n; i++) {
        if (!visited[i])
            DFS_bridge(i, -1);
    }
}

int main() {
    n = 5;

    adj[0].push_back(1);
    adj[1].push_back(0);

    adj[1].push_back(2);
    adj[2].push_back(1);

    adj[2].push_back(0);
    adj[0].push_back(2);

    adj[1].push_back(3);
    adj[3].push_back(1);

    adj[3].push_back(4);
    adj[4].push_back(3);

    findBridges();

    return 0;
}

The triangle 0 — 1 — 2 has no bridges: removing any one of its edges leaves the other two. The edges 1 — 3 and 3 — 4 are both bridges.

When to Use DFS vs BFS

3 min board

Use DFS when

  • finding cycles
  • topological sorting
  • finding strongly connected components
  • solving puzzles with backtracking
  • memory is limited (DFS uses less space for wide graphs)
  • exploring all paths

Use BFS when

  • finding the shortest path (unweighted)
  • level-order traversal
  • finding the distance from a source
  • finding if two vertices are connected in the minimum number of steps
  • the graph is very deep
