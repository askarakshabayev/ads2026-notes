Introduction to Heap

5 min board

What to say

  • A heap is a tree-based structure that satisfies the heap property: it is a complete binary tree, and every node follows one ordering rule with its children.
  • Two kinds. Max-heap: every parent ≥ its children, the root is the maximum. Min-heap: every parent ≤ its children, the root is the minimum.
  • Today we write the min-heap; the max-heap is the same code with the comparisons turned around.

Types of heaps

TypeRuleRoot holds
Max-Heapevery parent is greater than or equal to its childrenthe maximum
Min-Heapevery parent is less than or equal to its childrenthe minimum

The rule is only between a parent and its children. Nothing is said about two siblings or about left against right — that is the difference from a BST.

02

Heap Properties

4 min board

What to say

  • Complete binary tree: all levels are full except possibly the last, which is filled from left to right.
  • Because it is complete, the height is O(log n) — always, whatever order the keys arrive in.
  • And because it is complete, it is stored in an array, with no pointers.

Four properties

  • Complete Binary Tree: all levels are completely filled except possibly the last level, which is filled from left to right
  • Heap Property: the parent–child relationship follows the max-heap or min-heap rule
  • Array Representation: heaps are typically implemented using arrays (vectors) for efficiency
  • Height: O(log n) for n elements

Min-Heap Implementation

22 min code

What to say

  • Write the class top to bottom: the array and the three index formulas, then getMin, insert, heapify, extractMin, and main.
  • insert: put the element at the end, then bubble it up while it is smaller than its parent.
  • heapify: take the smaller child; if the node is bigger than it, swap and continue from there.
  • extractMin: remember the root, move the last element into the root, remove the last, heapify from the root.
  • main inserts n numbers and extracts them all — they come out sorted. That is heap sort, and it is the next part.

1 · The array and the index formulas

#include <iostream>
#include <vector>

using namespace std;

class MinHeap {
    public:
    vector<int> a;

    // Get parent index
    int parent(int i) {
        return (i - 1) / 2;
    }

    // Get left child index
    int left(int i) {
        return 2 * i + 1;
    }

    // Get right child index
    int right(int i) {
        return 2 * i + 2;
    }

    ...
};

The whole tree is one vector<int>. Parent and children are computed, not stored.

2 · getMin

// Get minimum element (root) - O(1)
int getMin() {
    return a[0];
}

The minimum of a min-heap is always at the root — index 0. O(1).

3 · insert — bubble up

// Insert element - O(log n)
void insert(int k) {
    // Add element at the end
    a.push_back(k);
    int ind = a.size() - 1;

    // Heapify up: bubble up the element
    while (ind > 0 && a[ind] < a[parent(ind)]) {
        swap(a[ind], a[parent(ind)]);
        ind = parent(ind);
    }
}

The new element goes to the end, so the tree stays complete. Then it rises while it is smaller than its parent — at most one swap per level.

4 · heapify — sift down

// Heapify down - O(log n)
void heapify(int i) {
    if (left(i) > a.size() - 1)
        return;

    // Find smallest among node and its children
    int j = left(i);
    if (right(i) < a.size() && a[right(i)] < a[left(i)])
        j = right(i);

    // If parent is greater than smallest child, swap and continue
    if (a[i] > a[j]) {
        swap(a[i], a[j]);
        heapify(j);
    }
}

Pick the smaller child — the right one only if it exists. If the node is bigger than it, swap and repeat one level down.

5 · extractMin

// Extract minimum element - O(log n)
int extractMin() {
    int root_value = getMin();

    // Replace root with last element
    swap(a[0], a[a.size() - 1]);
    a.pop_back();

    // Heapify down from root
    if (a.size() > 0)
        heapify(0);

    return root_value;
}

Moving the last element into the root keeps the tree complete; heapify then restores the order from the top.

6 · main

int main() {
    int n, x;

#include <iostream>
#include <vector>

using namespace std;

class MinHeap {
    public:
    vector<int> a;

    // Get parent index
    int parent(int i) {
        return (i - 1) / 2;
    }

    // Get left child index
    int left(int i) {
        return 2 * i + 1;
    }

    // Get right child index
    int right(int i) {
        return 2 * i + 2;
    }

    // Get minimum element (root) - O(1)
    int getMin() {
        return a[0];
    }

    // Insert element - O(log n)
    void insert(int k) {
        // Add element at the end
        a.push_back(k);
        int ind = a.size() - 1;

        // Heapify up: bubble up the element
        while (ind > 0 && a[ind] < a[parent(ind)]) {
            swap(a[ind], a[parent(ind)]);
            ind = parent(ind);
        }
    }

    // Heapify down - O(log n)
    void heapify(int i) {
        if (left(i) > a.size() - 1)
            return;

        // Find smallest among node and its children
        int j = left(i);
        if (right(i) < a.size() && a[right(i)] < a[left(i)])
            j = right(i);

        // If parent is greater than smallest child, swap and continue
        if (a[i] > a[j]) {
            swap(a[i], a[j]);
            heapify(j);
        }
    }

    // Extract minimum element - O(log n)
    int extractMin() {
        int root_value = getMin();

        // Replace root with last element
        swap(a[0], a[a.size() - 1]);
        a.pop_back();

        // Heapify down from root
        if (a.size() > 0)
            heapify(0);

        return root_value;
    }
};

int main() {
    int n, x;
    cin >> n;
    MinHeap *heap = new MinHeap();

    // Insert n elements
    for (int i = 0; i < n; i++) {
        cin >> x;
        heap->insert(x);
    }

    // Extract all elements (sorted order)
    for (int i = 0; i < n; i++)
        cout << heap->extractMin() << " ";

    return 0;
}

Heap Operations Explained

12 min board demo: heap

What to say

  • Insert — O(log n). Add at the end, compare with the parent, swap while smaller. Walk through inserting 5 on the board.
  • Extract min — O(log n). Save the root, replace it with the last element, remove the last, heapify down. Walk through it on the second example.
  • Heapify — O(log n). Compare with the children, find the smallest, swap if the node is not the smallest, repeat in that subtree.
  • Then let the demo do a few of each and read the swap counter — it never exceeds the height.

1 · Insert — O(log n)

  1. Add the element at the end of the array
  2. Compare with its parent
  3. If smaller than the parent (min-heap), swap
  4. Continue until the heap property is satisfied

Example: insert 5 into [10, 15, 20, 30, 40]. It lands at index 5, whose parent is index 2 — the value 20.

Step 1: [10, 15, 20, 30, 40, 5]  — add at end
Step 2: [10, 15, 5, 30, 40, 20]  — swap with parent (20)
Step 3: [5, 15, 10, 30, 40, 20]  — swap with parent (10)

Two swaps — the heap has three levels, so it could never take more than two.

2 · Extract min — O(log n)

  1. Save the root value (the minimum)
  2. Replace the root with the last element
  3. Remove the last element
  4. Heapify down from the root

Example: extract min from [10, 15, 20, 30, 40, 50].

Step 1: save 10 (minimum)
Step 2: [50, 15, 20, 30, 40]  — replace root with last
Step 3: [15, 50, 20, 30, 40]  — heapify: swap 50 with 15
Step 4: [15, 30, 20, 50, 40]  — heapify: swap 50 with 30
Result: return 10, heap is [15, 30, 20, 50, 40]

At each step 50 goes to the smaller child: 15 rather than 20, then 30 rather than 40.

3 · Heapify — O(log n)

  1. Compare the node with its children
  2. Find the smallest among the node and its children
  3. If the node is not the smallest, swap it with the smallest child
  4. Recursively heapify the affected subtree

Heap Sort Using Min-Heap

7 min board

What to say

  • The program from the implementation is already heap sort: build the heap by inserting everything, then extract the minimum n times.
  • Both halves are O(n log n), so the whole sort is O(n log n).

Build, then extract

  1. Build heap: insert all elements — O(n log n)
  2. Extract all: extract min repeatedly — O(n log n)

Practical Applications

What to say

  • Four places the same two operations — insert and extractMin — are all you need.
  • The priority queue is the main one: whatever has the smallest priority comes out first, no matter the order it went in.

1 · Priority queue

MinHeap pq;
pq.insert(5);  // Add task with priority 5
pq.insert(1);  // Add task with priority 1

// Process in priority order (1, 3, 5)
while (!pq.a.empty()) {

}

Tasks go in as 5, 1, 3 and come out as 1, 3, 5.

Potential Improvements

4 min code

What to say

  • getMin on an empty heap reads a[0] of an empty vector — undefined behaviour. Check first.
  • buildHeap makes a heap from a whole array at once: heapify every non-leaf node, from the last one back to the root. That is O(n), not O(n log n).

1 · Add a size check

int getMin() {
    if (a.empty()) {
        throw runtime_error("Heap is empty");
    }
    return a[0];
}

2 · Add a build-heap method

void buildHeap(vector<int> arr) {
    a = arr;
    // Start from last non-leaf node
    for (int i = a.size() / 2 - 1; i >= 0; i--) {
        heapify(i);
    }
}

The last non-leaf node is at n / 2 − 1; everything after it is a leaf and already a heap.

3 · Add a print function

void printHeap() {
    for (int i = 0; i < a.size(); i++)
        cout << a[i] << " ";
    cout << endl;
}

Max-Heap Implementation

4 min code

What to say

  • For a max-heap, reverse the comparisons — three places, each marked Change in the code.

Three comparisons flipped

class MaxHeap {
public:
    vector<int> a;

    int parent(int i) { return (i - 1) / 2; }
    int left(int i) { return 2 * i + 1; }
    int right(int i) { return 2 * i + 2; }

    int getMax() { return a[0]; }

    void insert(int k) {
        a.push_back(k);
        int ind = a.size() - 1;
        // Change: bubble up if GREATER than parent
        while (ind > 0 && a[ind] > a[parent(ind)]) {
            swap(a[ind], a[parent(ind)]);
            ind = parent(ind);
        }
    }

    void heapify(int i) {
        if (left(i) > a.size() - 1)
            return;
        int j = left(i);
        // Change: find LARGEST child
        if (right(i) < a.size() && a[right(i)] > a[left(i)])
            j = right(i);
        // Change: swap if parent is SMALLER
        if (a[i] < a[j]) {
            swap(a[i], a[j]);
            heapify(j);
        }
    }

    int extractMax() {
        int root_value = getMax();
        swap(a[0], a[a.size() - 1]);
        a.pop_back();
        if (a.size() > 0)
            heapify(0);
        return root_value;
    }
};

Common Questions

5 min

Q1 · Why is heapify O(log n)?

At each step we compare and possibly swap with one child, moving down one level. The heap height is log n, so there are at most log n steps.

Q2 · Build heap — O(n) or O(n log n)?

  • Inserting n elements one by one: O(n log n)
  • Building from an array (heapify from the bottom): O(n) — more efficient

Q3 · Why use a heap for sorting?

  • Guaranteed O(n log n) time
  • In-place if implemented correctly
  • No worst-case degradation like Quick Sort

Q4 · When to use a min-heap and when a max-heap?

  • Min-Heap: find the smallest elements, sort in ascending order
  • Max-Heap: find the largest elements, sort in descending order

Key Takeaways

2 min

Eight things to remember

  1. A min-heap always has the minimum at the root — O(1) access
  2. Insert and extract are O(log n)
  3. Heapify maintains the heap property by comparing with the children
  4. A complete binary tree stored in an array — space efficient
  5. Heap sort achieves O(n log n) by repeated extract operations
  6. Parent–child relationships are given by simple formulas
  7. No pointer manipulation — array indices handle the structure
  8. Perfect for a priority queue
