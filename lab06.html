When every value is a small number — here from 1 to 10 — count how many times each value occurs, then print each value that many times. There are no comparisons, and the work is O(n + k) for k possible values.

Bubble Sort: The Simple Algorithm

22 min board code

What to say

  • Bubble sort is the simplest sorting algorithm: walk through the list, compare adjacent elements, swap them if they are in the wrong order.
  • Repeat until a pass makes no swaps. After each pass the largest remaining element has "bubbled" to the end — that is why the inner loop gets one shorter every time.
  • Write out the first two passes on the board, then show the array after every pass.
  • Cost: O(n²) on average and in the worst case, O(n) when the array is already sorted — thanks to the swapped flag.
  • Then the number that ends the discussion: for a million elements, about 10¹² operations against about 2·10⁷ for quick sort.

How bubble sort works

  1. Compare adjacent elements
  2. Swap if they are in the wrong order
  3. Repeat until no swaps are needed

Bubble sort implementation

#include <iostream>
#include <vector>
using namespace std;

void bubbleSort(vector<int>& arr) {
    int n = arr.size();

    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;

        // Last i elements are already in place
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }

        // If no swapping happened, array is sorted
        if (!swapped)
            break;
    }
}

void printArray(vector<int>& arr) {
    for (int num : arr)
        cout << num << " ";
    cout << endl;
}

int main() {
    vector<int> arr = {64, 34, 25, 12, 22, 11, 90};

    cout << "Original array: ";
    printArray(arr);

    bubbleSort(arr);

    cout << "Sorted array:   ";
    printArray(arr);

    return 0;
}

Problems with bubble sort

  1. Inefficient for large datasets — O(n²) is too slow
  2. Too many comparisons — compares adjacent elements again and again
  3. Too many swaps — moves elements one position at a time
  4. Not suitable for real-world applications with large data

Example: sorting 1,000,000 elements

  • Bubble Sort: ~1,000,000,000,000 operations
  • Quick Sort: ~20,000,000 operations
  • about 50,000 times slower!

Another version · compare every pair

Even simpler: compare a[i] with every a[j] after it and swap if they are out of order. After step i the smallest remaining value sits at position i. Also O(n²), but no early stop.

Why We Need Quick Sort and Merge Sort

10 min board demo: race

What to say

  • Four reasons: much faster — O(n log n) against O(n²); they scale to millions of elements; they are what real systems use; and they are built on divide and conquer — break the problem into smaller subproblems.
  • Read the table row by row: at 100 elements the gap is 15×, at 100 000 it is 6 000×.

Advantages of the advanced algorithms

  1. Much faster: O(n log n) vs O(n²)
  2. Scalable: handle millions of elements efficiently
  3. Practical: used in real-world systems
  4. Divide and conquer: break the problem into smaller subproblems

Quick Sort

40 min board code demo: partition

What to say

  • Quick sort is divide and conquer: pick a pivot, partition the array around it, then recursively sort both parts.
  • Partition with two pointers: i walks right while a[i] < pivot, j walks left while a[j] > pivot; when both stop, swap and step on. When they cross, everything left of i is ≤ pivot and everything right of j is ≥ pivot.
  • Trace [10, 7, 8, 9, 1, 5] on the board with the code exactly as written — middle element as pivot.
  • Cost: O(n log n) when the pivot splits well, O(n²) when it is always the smallest or largest. Use the demo: pivot = first on an already sorted array.
  • Not stable, uses O(log n) stack on average — and it is the fastest sort in practice. Finish with the pivot strategies.

Quick sort algorithm

  1. Choose a pivot element from the array
  2. Partition: rearrange the array so elements < pivot are on the left and elements > pivot on the right
  3. Recursively apply the same steps to the left and right partitions

Quick sort implementation · the function

int a[1000];

void quick_sort(int l, int r) {
    // Choose middle element as pivot
    int p = a[(l + r) / 2];
    int i = l;
    int j = r;

    // Partition the array
    while (i < j) {
        // Find element on left that should be on right
        while (a[i] < p) i++;
        // Find element on right that should be on left
        while (a[j] > p) j--;

        // Swap elements if needed
        if (i <= j) {
            swap(a[i], a[j]);
            i++;
            j--;
        }
    }

    // Recursively sort left partition
    if (l < j)
        quick_sort(l, j);
    // Recursively sort right partition
    if (i < r)
        quick_sort(i, r);
}

Look at the first call: the pointers stop on the same cell, so the left part is [0..3] and the right part is [3..5] — they share index 3. With while (i < j) that can happen; the result is still sorted, only one cell is looked at twice. The common form while (i <= j) always separates the two parts.

Quick sort complexity

CaseTime ComplexitySpace Complexity
Best CaseO(n log n)O(log n)

Quick sort characteristics

Advantages

  • Fastest in practice for the average case
  • In-place sorting: uses O(log n) stack space
  • Cache-friendly: good locality of reference
  • Simple to implement

Disadvantages

  • Worst case O(n²): when the pivot is always the smallest or largest
  • Not stable: may change the relative order of equal elements
  • Recursive: uses stack space

Pivot selection strategies

  1. Last element: simple, but can be slow on sorted arrays
  2. First element: the same problem as the last element
  3. Random element: better average case
  4. Median of three: the median of the first, middle and last
  5. Median of medians: guaranteed O(n log n), but complex

The code above takes the middle element — on an already sorted array that is the median, the best possible split.

#include <iostream>

using namespace std;
int a[1000];

void quick_sort(int l, int r) {
    int p = a[(l + r) / 2];
    int i = l;
    int j = r;
    while (i < j) {
        while (a[i] < p) i++;
        while (a[j] > p) j--;
        if (i <= j) {
            swap(a[i], a[j]);
            i++;
            j--;
        }
    }
    if (l < j) 
        quick_sort(l, j);
    if (i < r)
        quick_sort(i, r);
}

    for (int i = 0; i < n; i++)
        cin >> a[i];
