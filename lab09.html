Prefix Function and KMP

One array, π, where π[i] is the longest proper prefix of s[0…i] that is also its suffix. It is computed in O(n), and run on pattern + "#" + text it finds every occurrence in O(n + m) with no false positives — then the same array answers periods, borders, rotations and palindromic prefixes.

Introduction

3 min

What to say

  • The Knuth–Morris–Pratt algorithm finds all occurrences of a pattern in a text in O(n + m) — n is the length of the text, m of the pattern.
  • Its key is the prefix function, which lets it search without redundant comparisons.

KMP in one sentence

Find every occurrence of a pattern in a text in O(n + m), using one precomputed array — the prefix function.

02

Prefix Function

32 min board code demo: π table

What to say

  • π[i] is the length of the longest proper prefix of s[0…i] that is also a suffix of s[0…i]. Proper means not the whole substring.
  • Do example 1 by the definition on the board — list the prefixes and suffixes for every i. Then examples 2 and 3 quickly.
  • The naive computation tries every length at every position: O(n³).
  • The efficient one starts from the previous answer j = π[i−1]. If s[i] == s[j], the answer is j + 1; otherwise fall back to π[j−1] and try again.
  • Trace "abcabcd" step by step, then let the demo step through other strings.

Definition

π[i] = length of the longest proper prefix of s[0…i]
that is also a suffix of s[0…i]

Proper prefix — a prefix that is not equal to the entire substring.

Naive approach — O(n³)

#include <iostream>
#include <vector>
using namespace std;

vector<int> prefix_function_naive(string s) {
    int n = s.size();
    vector<int> pi(n);

    pi[0] = 0;  // By definition

    for (int i = 1; i < n; i++) {
        // Try all possible lengths from longest to shortest
        for (int len = i; len > 0; len--) {
            // Check if prefix of length len equals suffix of length len
            bool match = true;
            for (int j = 0; j < len; j++) {
                if (s[j] != s[i - len + 1 + j]) {
                    match = false;
                    break;
                }
            }
            if (match) {
                pi[i] = len;
                break;
            }
        }
    }

    return pi;
}

int main() {
    string s = "abcabcd";
    vector<int> pi = prefix_function_naive(s);

    cout << "String: " << s << endl;
    cout << "Prefix function: ";
    for (int i = 0; i < pi.size(); i++)
        cout << pi[i] << " ";
    cout << endl;

    return 0;
}
output
String: abcabcd

Efficient approach — O(n)

  1. Start with π[0] = 0
  2. For each position i, look at the previous match length j = π[i−1]
  3. If s[i] == s[j], then π[i] = j + 1
  4. If s[i] != s[j], fall back to j = π[j−1] and try again
  5. Continue falling back until a match is found or j reaches 0
#include <iostream>
#include <vector>
using namespace std;

vector<int> prefix_function(string s) {
    int n = s.size();
    vector<int> pi(n);

    pi[0] = 0;  // First element is always 0

    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];  // Previous prefix length

        // Fall back until we find a match or reach 0
        while (j > 0 && s[i] != s[j]) {
            j = pi[j - 1];
        }

        // If characters match, increment the length
        if (s[i] == s[j]) {
            j++;
        }

        pi[i] = j;
    }

    return pi;
}

int main() {
    string s;
    cout << "Enter string: ";
    cin >> s;

    vector<int> pi = prefix_function(s);

    cout << "\nString:          ";
    for (int i = 0; i < s.size(); i++)
        cout << s[i] << " ";
    cout << endl;

    cout << "Index:           ";
    for (int i = 0; i < s.size(); i++)
        cout << i << " ";
    cout << endl;

    cout << "Prefix function: ";
    for (int i = 0; i < pi.size(); i++)
        cout << pi[i] << " ";
    cout << endl;

    return 0;
}

Knuth-Morris-Pratt (KMP) Algorithm

25 min board code

What to say

  • Find all occurrences of a pattern in a text. Glue them: pattern + "#" + text, where # appears in neither.
  • Compute π of the combined string. Wherever π[i] equals the pattern length, the pattern ends at i — it starts in the text at i − 2m.
  • The separator stops a match from running across the border between the pattern and the text.
  • Work the first example on the board column by column, then the second one with overlapping occurrences.

Problem and idea

Given a text (length n) and a pattern (length m), find all occurrences of the pattern in the text.

s = pattern + '#' + text
  • Compute the prefix function of the combined string
  • When π[i] equals the pattern length, a match is found
  • The separator keeps the pattern from matching across the boundary

KMP implementation

#include <iostream>
#include <vector>
using namespace std;

vector<int> prefix_function(string s) {
    int n = s.size();
    vector<int> pi(n);
    pi[0] = 0;

    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];

        while (j > 0 && s[i] != s[j]) {
            j = pi[j - 1];
        }

        if (s[i] == s[j]) {
            j++;
        }

        pi[i] = j;
    }

    return pi;
}

void KMP(string text, string pattern) {
    // Create combined string: pattern + '#' + text
    string s = pattern + "#" + text;

    int n = s.size();
    int m = pattern.size();

    // Compute prefix function
    vector<int> pi = prefix_function(s);

    // Find all occurrences
    for (int i = m + 1; i < n; i++) {
        // If prefix length equals pattern length, we found a match
        if (pi[i] == m) {
            // Position in text = i - m - m
            int pos = i - 2 * m;
            cout << "Pattern found at index " << pos << endl;
        }
    }
}

int main() {
    string text, pattern;

    cout << "Enter text: ";
    cin >> text;

    cout << "Enter pattern: ";
    cin >> pattern;

    cout << "\nSearching for pattern in text...\n" << endl;
    KMP(text, pattern);

    return 0;
}

Problems Solved Using Prefix Function and KMP

25 min code demo: period

What to say

  • One array, eight problems. Each of them is "build the right string, compute π, read one or a few values".
  • The period: if π[n−1] = k, the first k characters equal the last k, the shortest period has length n − k, and the string is periodic when n is divisible by it. Use the demo here.
  • Borders: π[n−1] is the longest one; jump k = π[k−1] to get every shorter one.

1 · Pattern matching

Find all occurrences of a pattern: create pattern + '#' + text and compute the prefix function.

void find_all_occurrences(string text, string pattern) {
    string s = pattern + "#" + text;
    vector<int> pi = prefix_function(s);
    int m = pattern.size();

    cout << "Pattern found at positions: ";
    for (int i = m + 1; i < s.size(); i++) {
        if (pi[i] == m) {
            cout << (i - 2 * m) << " ";
        }
    }
    cout << endl;
}

2 · Counting occurrences, overlapping included

Count how many times π[i] equals the pattern length.

int count_occurrences(string text, string pattern) {
    string s = pattern + "#" + text;
    vector<int> pi = prefix_function(s);
    int m = pattern.size();
    int count = 0;

    for (int i = m + 1; i < s.size(); i++) {
        if (pi[i] == m) {
            count++;
        }
    }

    return count;
}

3 · Shortest period of a string

"abcabcabc" has period "abc" — length 3.

int shortest_period(string s) {
    int n = s.size();
    vector<int> pi = prefix_function(s);

    int len = n - pi[n - 1];  // Length of shortest period

    // Check if string is actually periodic
    if (n % len == 0) {
        return len;
    } else {
        return n;  // No period (entire string)
    }
}

// Example: s = "abcabcabc"
// pi[8] = 6 (prefix "abcabc" = suffix "abcabc")
// len = 9 - 6 = 3
// 9 % 3 == 0 → period length is 3
example
s = "abcabcabc"
pi[8] = 6 (prefix "abcabc" = suffix "abcabc")
len = 9 - 6 = 3
9 % 3 == 0 → period length is 3
  • If π[n−1] = k, the first k characters match the last k
  • The shortest period has length n − k
  • If n is divisible by n − k, the string is periodic

4 · String compression

Can the string be written as a repeated pattern? Check whether the shortest period divides its length.

string compress(string s) {
    int n = s.size();
    int period_len = shortest_period(s);

    if (period_len < n) {
        int count = n / period_len;
        string pattern = s.substr(0, period_len);
        return pattern + " × " + to_string(count);
    }

    return s;  // Cannot compress
}

// Example: "abcabcabc" → "abc × 3"
// Example: "abcdef" → "abcdef" (no compression)
example
"abcabcabc" → "abc × 3"
"abcdef"    → "abcdef" (period 6 = whole string, no compression)

5 · Pattern in a cyclic string

Does the pattern occur in some rotation of the text? Search in text + text.

bool pattern_in_rotation(string text, string pattern) {
    string doubled = text + text;
    string s = pattern + "#" + doubled;
    vector<int> pi = prefix_function(s);
    int m = pattern.size();

    for (int i = m + 1; i < s.size(); i++) {
        if (pi[i] == m) {
            return true;
        }
    }

    return false;
}

// Example: text = "abcde", pattern = "dea"

6 · Longest palindromic prefix

Compute the prefix function of s + '#' + reverse(s); the last value is the answer.

int longest_palindrome_prefix(string s) {
    string rev = s;
    reverse(rev.begin(), rev.end());

    string combined = s + "#" + rev;
    vector<int> pi = prefix_function(combined);

    return pi[combined.size() - 1];
}

// Example: s = "abacaba"
// rev = "abacaba"
// combined = "abacaba#abacaba"
// π[14] = 7 → entire string is palindrome

7 · All borders

All lengths k for which the prefix of length k equals the suffix of length k: start from π[n−1] and keep jumping back.

vector<int> find_all_borders(string s) {
    int n = s.size();
    vector<int> pi = prefix_function(s);
    vector<int> borders;

    int k = pi[n - 1];
    while (k > 0) {
        borders.push_back(k);
        k = pi[k - 1];
    }

    reverse(borders.begin(), borders.end());
    return borders;
}

// Example: s = "abcabcab"
// Borders: lengths 2, 5 ("ab", "abcab")

8 · Several patterns

For each pattern, build its own pattern + '#' + text.

void find_multiple_patterns(string text, vector<string> patterns) {
    for (int k = 0; k < patterns.size(); k++) {
        string s = patterns[k] + "#" + text;
        vector<int> pi = prefix_function(s);
        int m = patterns[k].size();

        for (int i = m + 1; i < s.size(); i++) {
            if (pi[i] == m) {
                cout << "Pattern " << k << " (\"" << patterns[k];
                cout << "\") found at index " << (i - 2 * m) << endl;
                break;  // Found first occurrence
            }
        }
    }
}

Advantages and Disadvantages

3 min

Advantages

  • Guaranteed O(n + m) time — no worst-case degradation
  • No false positives — always correct
  • Simple, elegant approach — using pattern + '#' + text
  • The prefix function is versatile — it solves many problems
  • No backtracking — one linear scan

Disadvantages

  • Extra space — O(n + m) for the combined string
  • Preprocessing required — compute the prefix function
  • Very long texts — the whole combined string has to be stored
  • Single pattern — repeat the work for each pattern

Common Questions

6 min

Q1 · Why do we need the separator '#'?

Without it the pattern could match across the boundary between the pattern and the text, giving wrong results.

pattern = "ab", text = "cab"
Without #: "abcab" → would match at position 0 (wrong!)
With #:    "ab#cab" → no match (correct!)

In "abcab", π[4] = 2 = m, so the formula reports position 4 − 2×2 = 0 — but in "cab" the pattern starts at index 1.

Q2 · What if '#' appears in the text or the pattern?

Choose a separator that appears in neither:

  • '#' if only letters are used
  • '$' for printable ASCII
  • any character with a code larger than every character of the alphabet

Q3 · Why is this simpler than traditional KMP?

Traditional KMP moves a pointer in the pattern and a pointer in the text and has to handle both carefully. The combined string reduces it to one loop that checks π[i] == m.

Q4 · Can we save space?

Yes — the prefix function can be computed on the fly without storing the whole combined string, but the code becomes more complex.

Q5 · Why is the prefix function O(n)?

There is a while loop inside the for loop, but j grows by at most 1 per iteration — at most n times in total — so it can also decrease at most n times in total. Overall: O(n).

Key Takeaways

2 min

Eight things to remember

  1. The prefix function is the key — the longest proper prefix that is also a suffix
  2. Pattern matching with pattern + '#' + text — elegant and simple
  3. O(n + m) guaranteed — no worst-case degradation
  4. When π[i] = m, the pattern is found — at position i − 2m
  5. The separator '#' is essential — it prevents false matches
  6. The prefix function is O(n)
  7. Many applications — periods, compression, palindromes
  8. No false positives — unlike hashing
