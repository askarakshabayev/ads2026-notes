Node Implementation

8 min code

What to say

  • Every structure today is made of nodes: a value and a pointer to the next node. The last node points to NULL.
  • Write the class, create a few nodes with new, link them by hand, and walk the chain with ->next->next.
  • The template version is the same node for any type — Node<string>, Node<int>.

Basic node structure

#include <iostream>
using namespace std;

class Node {
    public:
    int data;
    Node *next;

    Node(int data) {
        this->data = data;
        this->next = NULL;
    }
};

A value and one pointer. A new node points nowhere yet, so next starts as NULL.

n1 → [10|•] → [20|•] → [30|✕]

Template node for generic types

template<typename T>
class Node {
    public:
    T data;
    Node<T> *next;

    Node(T data) {
        this->data = data;
        this->next = NULL;
    }
};

int main() {
    Node<string> *n1 = new Node<string>("hello");
    Node<string> *n2 = new Node<string>("world");
    Node<string> *n3 = new Node<string>("test");
    n1->next = n2;
    n2->next = n3;
    cout << n1->next->next->data;
    return 0;
}
output
test

n1->next->next is the third node, so the program prints its value.

Stack — LIFO (Last In, First Out)

12 min code

What to say

  • A stack of plates: you only add to the top and take from the top. Last in, first out.
  • Every operation is O(1) — push, pop, top, empty, size.
  • First the STL stack, then the same thing on nodes: the top of the stack is the head of the chain, push puts a new node in front of it.

Core operations

  • push(item) — add an item to the top — O(1)
  • pop() — remove the top item — O(1)
  • top() / peek() — view the top item without removing it — O(1)
  • empty() — check if the stack is empty — O(1)
  • size() — get the number of elements — O(1)

C++ implementation using STL

// C++ built-in stack
#include <iostream>
#include <stack>
using namespace std;

int main() {
   stack<int> st;
   st.push(10);
   st.push(20);
   st.push(15);
   st.push(1);

   cout << st.top() << endl; // 1
   st.pop();
   st.pop();
   cout << st.top() << endl; // 20
   cout << st.size() << endl;
   cout << st.empty();
   return 0;
}
output
1
20
2
0

After pushing 10, 20, 15, 1 the top is 1; two pops remove 1 and 15, so the top is 20 and two elements are left. empty() prints as 0 — false.

Custom stack implementation

class Stack {
    public:
    Node *top;
    int sz;

    Stack() {
        top = NULL;
        sz = 0;
    }

    void push(int data) {
        Node *node = new Node(data);
        node->next = top;
        top = node;
        sz++;
    }

    void pop() {
        if (top != NULL) {
            top = top->next;
            sz--;
        }
    }

    int size() {
        return this->sz;
    }

    bool empty() {
        return (sz == 0);
    }
};

push: the new node points at the old top and becomes the top. pop: the top moves one node down.

    }
};

    Node *top;
    int sz;

    Stack() {
        top = NULL;
        sz = 0;
    }

    void push(int data) {
        Node *new_node = new Node(data);
        new_node->next = top;
        top = new_node;
        sz++;
    }

    void pop() {
        if (top == NULL)
            return;
        Node *old = top;
        top = top->next;
        delete old;   // added: free the removed node
        sz--;

        return sz == 0;

        return sz;
    }
};

    st->push(20);
    st->push(30);

}

Stack Problems

12 min code

What to say

  • Start with only round brackets and no stack: a counter goes up on ( and down on ). It must never go negative and must end at zero.
  • Then ask what breaks with three kinds of brackets. A counter cannot tell ( from [ — we need to remember which bracket was opened last. That is exactly a stack.
  • The stack version: push every opening bracket; on a closing one, the top must be its pair — pop it. At the end the stack must be empty.

Simple problem · basic parentheses balance

Check if only () brackets are properly balanced. Try solving without a stack first:

#include <iostream>
using namespace std;

// Simple counter approach - works only for () brackets
bool simple_balance(string s) {
    int counter = 0;
    
    for (int i = 0; i < s.size(); i++) {
        if (s[i] == '(') {
            counter++;
        } else if (s[i] == ')') {
            counter--;
            // If counter goes negative, we have ')' before '('
            if (counter < 0) {
                return false;
            }
        }
    }
    
    // Should end with counter = 0
    return (counter == 0);
}

int main() {
    string s;
    cin >> s;
    if (simple_balance(s))
        cout << "YES";
    else
        cout << "NO";
    return 0;
}

Examples:

  • "()" → True
  • "(())" → True
  • "(((" → False
  • ")))" → False
  • "()(" → False

Why this approach fails for multiple bracket types

  • A counter cannot distinguish between different bracket types
  • Count every opening bracket as +1 and every closing one as −1, and "(]" or "([)]" come out balanced — both are accepted, which is wrong
  • We need to remember which opening bracket we saw

Classic problem · balanced brackets

Check if brackets are properly balanced: (), [], {}.

#include <iostream>
#include <stack>
using namespace std;

bool is_ok(string s) {
    stack<char> st;

    for (int i = 0; i < s.size(); i++) {
        if (s[i] == '(' || s[i] == '{' || s[i] == '[')
            st.push(s[i]);
        else {
            if (st.empty())
                return false;
            if (s[i] == '}' && st.top() != '{')
                return false;
            if (s[i] == ']' && st.top() != '[')
                return false;
            if (s[i] == ')' && st.top() != '(')
                return false;
            st.pop();                
        }
    }
    return (st.empty());
}

int main() {
    string s;
    cin >> s;
    if (is_ok(s))
        cout << "YES";
    else
        cout << "NO";
    return 0;
}

Examples:

  • "()" → True
  • "([{}])" → True
  • "([)]" → False
  • "(((" → False

Applications: function call management, expression evaluation, undo operations, browser history.

Queue — FIFO (First In, First Out)

8 min code

What to say

  • A line at a store: the first person in line is served first. First in, first out.
  • Elements come in at the rear and leave from the front; all operations are O(1).
  • The queue is what breadth-first search runs on — the two problems after the deque are both BFS.

Core operations

  • push() / enqueue(item) — add an item to the rear — O(1)
  • pop() / dequeue() — remove the front item — O(1)
  • front() — view the front item without removing it — O(1)
  • empty() — check if the queue is empty — O(1)
  • size() — get the number of elements — O(1)

C++ implementation using STL

#include <queue>
#include <iostream>
using namespace std;

void demo_stl_queue() {
    queue<int> q;
    
    // Add elements
    q.push(10);
    q.push(20);
    q.push(30);
    
    cout << "Queue size: " << q.size() << endl;
    cout << "Front element: " << q.front() << endl;
    
    // Remove elements
    while (!q.empty()) {
        cout << "Removing: " << q.front() << endl;
        q.pop();
    }
}

Applications

  • Task scheduling in operating systems
  • Breadth-First Search (BFS) in graphs
  • Print job management
  • Buffer for data streams

Another version · queue on nodes

The same queue built from nodes: front is where elements leave, end is where they arrive. When the last element leaves, both become NULL.

class Queue {
    public:
    Node *front;
    Node *end;
    Queue() {
        front = NULL;
        end = NULL;
    }
    void push(int val) {
        Node* newNode = new Node(val);
        if (end == NULL) {
            front = end = newNode;
            return;
        }
        end->next = newNode;
        end = newNode;
    }
    void pop() {
        if (front == NULL) 
            return;
        Node* temp = front;
        front = front->next;
        if (front == NULL) 
            end = NULL;
        delete temp;
    }
    int peek() {
        if (front == NULL) 
            return -1; // or throw an exception
        return front->data;
    }
    int empty() {   
        return front == NULL;
    }
    int size() {
        int count = 0;
        Node* current = front;
        while (current != NULL) {
            count++;
            current = current->next;
        }
        return count;
    }

};

Deque — Double-Ended Queue

5 min code

What to say

  • A combination of a stack and a queue: add and remove at both ends, all in O(1).
  • Trace the four lines on the board: push_front puts the element before everything else.

Core operations

  • push_back(item) — add an item to the back — O(1)
  • push_front(item) — add an item to the front — O(1)
  • pop_back() — remove the back item — O(1)
  • pop_front() — remove the front item — O(1)

q.push_front(30);

Problem: Minimum Operations to Transform Number

12 min code BFS

What to say

  • Given a and b, the fewest operations +1, ×2, ÷2, −1 that turn a into b.
  • Every number is a state, every operation is a step. BFS visits states in order of distance, so the first time it reaches b the distance is minimal.
  • used[x] stores the number we came from — that is how the path is printed backwards from b.

Problem statement

Given two positive integers a and b, find the minimum number of operations needed to transform a into b:

  • Add 1: x → x + 1
  • Multiply by 2: x → x * 2
  • Divide by 2: x → x / 2 (integer division)
  • Subtract 1: x → x − 1 (if the result ≥ 0)

Example: a = 2, b = 12 → 3 operations, path 2 → 3 → 6 → 12.

Algorithm · BFS guarantees the minimum

#include <iostream>
#include <queue>
using namespace std;

queue<pair<int, int> > q;
int used[1000]; 

int f(int a, int b) {
    q.push(make_pair(a, 0));
    used[a] = a;

    while (!q.empty()) {
        int x = q.front().first;
        int d = q.front().second;

        if (x == b) {
            return d;
        }

        if (x + 1 < 1000 && used[x + 1] == 0) {   // stay inside used[]
            q.push(make_pair(x + 1, d + 1));
            used[x + 1] = x;
        }

        if (x * 2 < 1000 && used[x * 2] == 0) {   // stay inside used[]
            q.push(make_pair(x * 2, d + 1));
            used[x * 2] = x;
        }

        if (used[x / 2] == 0) {
            q.push(make_pair(x / 2, d + 1));
            used[x / 2] = x;
        }

        if (x - 1 >= 0 && used[x - 1] == 0) {
            q.push(make_pair(x - 1, d + 1));
            used[x - 1] = x;
        }
        q.pop();
    }
    return 0;
}

int main() {
    int a, b;
    cin >> a >> b;
    cout << f(a, b) << endl;

    vector<int> result;
    result.push_back(b);
    int t = b;
    while (used[t] != t) {
        t = used[t];
        result.push_back(t);
    }

    for (int i = result.size() - 1; i >= 0; i--)
        cout << result[i] << " ";

    return 0;
}
input
2 12
output
3
2 3 6 12

The first line is the number of operations, the second the path. The two range checks keep x + 1 and x * 2 inside used[1000].

Problem: Knight's Shortest Path on Chessboard

10 min code BFS

What to say

  • Same BFS, different states: a state is a square, a step is one of the eight knight moves.
  • a[x][y] is both "visited" and the distance (+1, because the start is marked 1); c[x][y] is the square we came from.

Problem statement

On a standard 8×8 chessboard, find the minimum number of moves for a knight to travel from (x1, y1) to (x2, y2).

BFS over the board

#include <iostream>
#include <queue>
using namespace std;

int a[10][10];
pair<int, int> c[10][10];
queue<pair<int, int> > q;

int dx[8] = {2,  2, -2, -2,  1, 1, -1, -1};
int dy[8] = {1, -1,  1, -1, -2, 2, -2,  2};

bool check(int x, int y) {
    return (x >= 1 && x <= 8 && y >= 1 && y <= 8 && a[x][y] == 0);
}

int main() {
    int x1, y1, x2, y2;
    cin >> x1 >> y1 >> x2 >> y2;
    a[x1][y1] = 1;
    q.push(make_pair(x1, y1));
    c[x1][y1] = make_pair(x1, y1);

    while (!q.empty()) {
        int x = q.front().first;
        int y = q.front().second;

        for (int i = 0; i < 8; i++) {
            if (check(x + dx[i], y + dy[i])) {
                q.push(make_pair(x + dx[i], y + dy[i]));
                a[x + dx[i]][y + dy[i]] = a[x][y] + 1;
                c[x + dx[i]][y + dy[i]] = make_pair(x, y);
            }
        }
        q.pop();
    }

    cout << a[x2][y2] - 1 << endl;

    vector<pair<int, int> > result;
    result.push_back(make_pair(x2, y2));
    int x = x2;
    int y = y2;
    while (c[x][y] != make_pair(x, y)) {
        int x_temp = c[x][y].first;
        int y_temp = c[x][y].second; 
        result.push_back(make_pair(x_temp, y_temp));
        x = x_temp;
        y = y_temp;
    }

    for (int i = result.size() - 1; i >= 0; i--)
        cout << result[i].first << " " << result[i].second << endl;
    return 0;
}
input
1 1 8 8
output
6
1 1
3 2
5 3
7 4
5 5
7 6
8 8

Six moves from one corner to the opposite one, then the squares of one shortest path.

Linked List

25 min code demos

What to say

  • A doubly linked list: every node has next and prev, the list keeps front and tail.
  • Write it function by function: push_back and push_front, pop_back and pop_front, delete a node you hold, print, find, insert after a node.
  • Each function has an empty-list case and a one-element case — say them out loud every time.
  • Deleting a node you hold is O(1): its neighbours are one pointer away in both directions.

3 · pop_back and pop_front

void pop_back() {
    if (tail != NULL) {
        tail = tail->prev;
        if (tail != NULL)
            tail->next = NULL;
        else 
            front = NULL;
    }
}

void pop_front() {
    if (front != NULL) {
        front = front->next;
        if (front != NULL)
            front->prev = NULL;
        else
            tail = NULL;
    }
}

When the last element leaves, both ends become NULL.

4 · Delete a node

void del_node(Node *node) {
    if (node == tail)
        pop_back();
    else if (node == front) 
        pop_front();
    else {
        Node *a = node->prev;
        Node *b = node->next;
        a->next = b;
        b->prev = a;
    }
}

Tail and front are special; any other node is unlinked by joining its two neighbours.

class LinkedList {
    public:
    Node *tail;
    Node *front;
    int data;

    LinkedList() {
        tail = front = NULL;
    }

    void push_front(int data) {
        Node *node = new Node(data);
        if (front == NULL) {
            front = tail = node;
        } else {
            node->next = front;
            front->prev = node;
            front = node;
        }
    }

    void push_back(int data) {
        Node *node = new Node(data);
        if (front == NULL) {
            front = tail = node;
        } else {
            tail->next = node;
            node->prev = tail;
            tail = node;
        }
    }
    
    void pop_back() {
        if (tail != NULL) {
            Node *temp = tail;
            tail = tail->prev;
            if (tail != NULL)
                tail->next = NULL;
            else
                front = NULL;   // added: the list is empty now
            delete temp;            
        }
    }

    void del_node(Node *node) {
        if (node == tail)
            this->pop_back();
        else if (node == front) {
            front = front->next;   // added: this case did nothing
            front->prev = NULL;
            delete node;
        } else {
            Node *a = node->prev;
            Node *b = node->next;
            a->next = b;
            b->prev = a;
            delete node;           // added: free the removed node
        }
    }
};

class Stack {
    public:
    Node* top;
    int sz;
    Stack() {
        top = NULL;
        sz = 0;
    }
    void push(int val) {
        Node *newNode = new Node(val);
        newNode->next = top;
        top = newNode;
        this->sz++;
    }

    int peek() {
        if (top == NULL) 
            return -1; // or throw an exception
        return top->data;
    }
    int size() {
        return sz;
    }
    int empty() {
        return sz == 0;
    }
};

class Queue {
    public:
    Node *front;
    Node *end;
    Queue() {
        front = NULL;
        end = NULL;
    }
    void push(int val) {
        Node* newNode = new Node(val);
        if (end == NULL) {
            front = end = newNode;
            return;
        }
        end->next = newNode;
        end = newNode;
    }
    void pop() {
        if (front == NULL) 
            return;
        Node* temp = front;
        front = front->next;
        if (front == NULL) 
            end = NULL;
        delete temp;
    }
    int peek() {
        if (front == NULL) 
            return -1; // or throw an exception
        return front->data;
    }
    int empty() {   
        return front == NULL;
    }
    int size() {
        int count = 0;
        Node* current = front;
        while (current != NULL) {
            count++;
            current = current->next;
        }
        return count;
    }

};

class SinglyLinkedList {   // renamed: the file already has a LinkedList above
    public:
    Node* head;
    Node* tail;
    int sz;
    SinglyLinkedList() {
        head = NULL;
        tail = NULL;
        sz = 0;
    }

    void insert_at_head(int val) {
        Node* newNode = new Node(val);
        if (head == NULL) {
            head = tail = newNode;
        } else {
            newNode->next = head;
            head = newNode;
        }
        sz++;
    }

    void insert_at_tail(int val) {
        Node* newNode = new Node(val);
        if (tail == NULL) {
            head = tail = newNode;
        } else {
            tail->next = newNode;
            tail = newNode;
        }
        sz++;
    }

    void delete_from_head() {
        if (head == NULL) 
            return;
        Node* temp = head;
        head = head->next;
        if (head == NULL) 
            tail = NULL;
        delete temp;
        sz--;
    }

    void delete_from_tail() {
        if (tail == NULL) 
            return;
        if (head == tail) {
            delete head;
            head = tail = NULL;
            sz--;
            return;
        }
        Node* current = head;
        while (current->next != tail) {
            current = current->next;
        }
        delete tail;
        tail = current;
        tail->next = NULL;
        sz--;
    }

    int size() {
        return sz;
    }

    bool empty() {
        return sz == 0;
    }
};

Key Takeaways

3 min

Six things to remember

  1. Choose the right data structure based on your access patterns
  2. Stack: when you need LIFO behaviour — undo operations, function calls
  3. Queue: when you need FIFO behaviour — BFS, task scheduling
  4. Deque: when you need both stack and queue operations
  5. Linked List: when frequent insertions and deletions and a dynamic size matter
  6. Understanding pointers and memory management is crucial for implementing these structures
